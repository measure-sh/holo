# Keymap

## Global

| Key | Action |
|-----|--------|
| qq | Quit |
| ss | Settings |
| ^D | Select device |
| ^A | Select app |
| 0 | Toggle commands panel |
| 1-9 | Toggle panel visibility |
| z | Zoom in/out (when focused) |

## Commands (^shortcut)

| Key | Action |
|-----|--------|
| ^O | Open app |
| ^K | Kill app |
| ^W | Wake screen |
| ^R | Mirror device |
| ^X | Clear data |
| ^N | Dark mode (device) |
| ^S | Screenshot |
| ^L | Layout bounds |
| ^F | WiFi |
| ^I | Airplane mode |
| ^B | Wireless ADB |
| ^U | Uninstall |
| ^T | Show taps |
| ^P | Pointer location |
| ^G | GPU rendering |
